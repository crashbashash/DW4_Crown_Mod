# v0.7.0 native application and regional runtime checks

Verified on 2026-10-15 against source commit `1c41f39` (tag `v0.7.0`).
All three regional discs were created through the native Tauri application,
then cold booted in PCSX2 and taken through the World 1 gate into Goblin Pass.
All three complete patched enemy-table blocks were found in each live session.

## Application checks

The opt-in `agent-control` build drove the rendered React UI and native Rust
patch engine, using the path fields and Patch ISO button. This was not the
browser mock backend. USA used a debug build; Europe and Japan used an optimized
build of the same commit.

`tools/e2e.py` passed all seven checks for every region:

1. Patch disabled without an input; only the base mode is available.
2. Invalid disc refused.
3. Output matches the reference MD5; original unchanged; no leftover part file.
4. Existing output asks before replacement; cancellation preserves it.
5. Confirmed overwrite succeeds and retains the expected output checksum.
6. Output equal to input is refused, preserving the original.
7. Already-modded output is refused as a new input.

| Region | Native UI | Output ISO MD5 | Boot ELF / CRC |
| --- | --- | --- | --- |
| USA | Pass | `df426b9ff17c9e8218779f8ff1ecf524` | `SLUS_208.36` / `B871C1D0` |
| Europe | Pass | `f7f04d92915e7dc8b650d3d9faa1e55f` | `SLES_534.05` / `2CEFF37C` |
| Japan | Pass | `5352edd1f061be9c94c9eeb07807023a` | `SLPS_254.53` / `E4F97921` |

## Runtime checks

The private PCSX2 build with PINE control protocol 2 used separate regional
profiles, software rendering, and disabled compatibility patches and cheats.
The boot commands pointed to the actual files produced by the application.
No existing savestate was loaded. PCSX2 identified each expected regional ELF;
Europe used PAL output, and Japan retained its Japanese title and menus.

Each region passed character/card loading, arrival in the hub without the intro
replay, movement and jumping to the world gate, selection of Death Valley, and
loading Goblin Pass. Screenshots record the active World 1 option and loaded area.

The initial historical `op_save` fixture replayed the introduction despite
having Hard unlocked. It was replaced with separate regional test cards using
DW4orge's save library. These use the World 1 chapter (flag 2), commander unlock
(flag 20), intro/practice markers and the corresponding Normal difficulty
mirrors. Both save-block checksums and card ECC were generated by DW4orge.
The World 1 gate was checked visually in every region; original cards were not
modified.

After each area loaded, a new native savestate was captured and its EE memory
was extracted offline. The entire HP (2,596 bytes), stats (15,576 bytes), and
chargen/crown (1,947 bytes) arrays matched the patched disc byte-for-byte:

| Region | HP RAM address | Stats RAM address | Chargen RAM address |
| --- | --- | --- | --- |
| USA | `0x01708720` | `0x01712E70` | `0x017126D0` |
| Europe | `0x017087B0` | `0x01712F00` | `0x01712760` |
| Japan | `0x0170D698` | `0x017140A0` | `0x01713900` |

The matching block MD5s are respectively `56885ddab3be87476c0810abf6b6f152`,
`42df4de8f3afc8f032a16e293cc1e3ab`, and `3ce7d29cd12e93d05eb201356b231288`.
This confirms a fresh regional area load uses the mod's table data.
