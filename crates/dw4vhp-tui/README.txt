DW4 Crown Mod - terminal version for Windows 7 and later
=========================================================

This is the same patcher as the desktop app, in a console window. It runs on
Windows 7 SP1 64-bit and later and needs nothing else installed.

Starting
  - Double-click dw4-crown-mod-tui.exe, or
  - drag your disc image onto dw4-crown-mod-tui.exe to start with it chosen.

Choosing your disc
  Type the path to your clean, original disc image (.iso, .gcm, .ciso or .rvz)
  and press Enter. You can also drag the file onto the console window, or
  right-click in the window and choose Paste.

Keys
  Up/Down    move between options
  Space      turn the highlighted option on or off
  Enter      continue
  Esc        go back
  L / S      load or save a settings file (shared with the desktop app)
  R          new enemy seed (when the seed is highlighted)
  Ctrl+U     clear a text field

Your original disc image is never changed. The patched game is written next to
it unless you choose another path. Random enemies can take several minutes;
keep the window open until it says Done.
